주소 좌표 변환기

엑셀의 주소 열을 읽어 오른쪽에 위도·경도를 채워 내려받습니다. 카카오 지도 좌표를 사용합니다.

?사용 가이드▾

처음 한 번만 · 카카오 키 준비

  1. developers.kakao.com에 로그인하고 내 애플리케이션 › 애플리케이션 추가로 앱을 만듭니다.
  2. 앱 › 요약 정보에서 JavaScript 키를 복사합니다. REST API 키가 아닙니다.
  3. 앱 › 플랫폼 › Web › 사이트 도메인 등록에 이 앱의 주소를 경로 없이 오리진만 넣습니다. 예: https://아이디.github.io
도메인을 등록하지 않으면 좌표 조회가 실패합니다. 파일을 그냥 더블클릭(file://)해서 열어도 동작하지 않으니, 배포된 주소로 접속해 사용하세요.

변환하기

  1. 1단계에 JavaScript 키를 붙여넣고 저장하고 연결을 누릅니다. 키는 이 기기에 저장돼 다음부터 자동 연결됩니다.
  2. 2단계에 엑셀 파일을 끌어다 놓거나 눌러서 선택합니다. 첫 시트의 1행을 머리글로 읽습니다.
  3. 3단계에서 주소가 든 열을 확인하고(‘주소’ 열은 자동 선택) 변환 시작을 누릅니다.
  4. 진행이 끝나면 결과 엑셀 내려받기로 저장합니다. 주소 열 오른쪽에 위도·경도가 추가됩니다.

알아두면 좋은 점

  • 모든 처리는 브라우저 안에서만 이뤄집니다. 파일이 서버로 올라가지 않습니다.
  • 도로명·지번 검색이 실패하면 장소명(키워드) 검색으로 한 번 더 시도합니다.
  • 실패한 행은 실패 항목 다시 변환으로 재시도할 수 있습니다. 주소를 도로명 형식으로 다듬으면 성공률이 올라갑니다.
  • 좌표계는 WGS84(위경도)입니다.
  • 모바일 브라우저의 홈 화면에 추가를 누르면 앱처럼 설치돼 실행됩니다.
